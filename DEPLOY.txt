================================================================
  КАК ПОСТАВИТЬ САЙТ НА СЕРВЕР
  Ubuntu 24.04, доступ по IP (без домена)
================================================================

ЧТО ПОНАДОБИТСЯ
  - IP сервера (например 123.45.67.89)
  - пароль root от сервера
  - 30-40 минут времени

КАК ЭТО РАБОТАЕТ (в двух словах)
  1. React собирается в обычные файлы (папка dist) — их отдаёт nginx.
  2. Express (backend) работает на порту 3000 и хранит заказы в orders.json.
  3. nginx показывает сайт и перенаправляет запросы /api/... в Express.
  4. systemd следит, чтобы Express не падал и запускался после перезагрузки.

Итог: в браузере открываешь http://IP — видишь сайт.


================================================================
ШАГ 0. ПОДКЛЮЧИТЬСЯ К СЕРВЕРУ
================================================================
[ ] Открой терминал (PowerShell) и введи:

    ssh root@IP

    (вместо IP — адрес сервера; пароль при вводе не отображается, это нормально)

Проверка: приглашение командной строки стало вида  root@ubuntu:~#


================================================================
ШАГ 1. ОБНОВИТЬ СИСТЕМУ И ПОСТАВИТЬ ПРОГРАММЫ
================================================================
[ ] Выполни по очереди:

    apt update && apt upgrade -y

    apt install -y nginx git curl

    curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
    apt install -y nodejs

[ ] Проверь, что Node правильной версии:

    node -v

    Должно быть v22.x.x

ВАЖНО: в Ubuntu своя старая Node, поэтому ставим через NodeSource.
Vite 8 на старой версии просто не запустится.


================================================================
ШАГ 2. СКАЧАТЬ ПРОЕКТ
================================================================
[ ] Скачай репозиторий на сервер:

    mkdir -p /opt/okna
    cd /opt/okna
    git clone https://github.com/kirilikl/oknaProject.git .

    (точка в конце обязательна — она означает "сюда")

Проверка:

    ls

    Должны увидеть: backend  src  package.json  vite.config.js  ...

ЕСЛИ РЕПОЗИТОРИЙ ПРИВАТНЫЙ (просит логин/пароль):
    либо сделай его публичным на GitHub,
    либо залей файлы с компьютера (выполняется НА КОМПЬЮТЕРЕ, не на сервере):

    scp -r C:\Users\Kirill\oknaProject/* root@IP:/opt/okna/

    (папку node_modules можно не заливать — на сервере она не нужна)


================================================================
ШАГ 3. УСТАНОВИТЬ ЗАВИСИМОСТИ И СОБРАТЬ САЙТ
================================================================
[ ] Собери фронтенд:

    cd /opt/okna
    npm ci
    npm run build

    На 1 ядре сборка идёт около минуты.

[ ] Поставь зависимости бэкенда:

    cd /opt/okna/backend
    npm ci --omit=dev

Проверка: должна появиться папка /opt/okna/dist — это и есть готовый сайт.


================================================================
ШАГ 4. ЗАПУСТИТЬ БЭКЕНД (чтобы работал всегда)
================================================================
[ ] Создай файл /etc/systemd/system/okna-api.service:

    nano /etc/systemd/system/okna-api.service

    Вставь туда:

--------- начало файла ---------
[Unit]
Description=Okna API
After=network.target

[Service]
WorkingDirectory=/opt/okna/backend
Environment=PORT=3000
ExecStart=/usr/bin/node server.js
Restart=always

[Install]
WantedBy=multi-user.target
--------- конец файла ---------

    Сохранить: Ctrl+O, Enter, затем выйти: Ctrl+X

[ ] Запусти:

    systemctl daemon-reload
    systemctl enable --now okna-api

[ ] Проверь:

    curl -i http://127.0.0.1:3000/api/orders

    Должен вернуться код 401 (Доступ запрещен) — это значит сервер жив
    и правильно просит пароль.

ПРО ПАРОЛЬ: он сейчас зашит в backend/server.js и равен  admin123.
Если захочешь поменять — это строка
    const ADMIN_PASSWORD = process.env.ADMIN_PASSWORD || "admin123"
Для учебного проекта можно оставить как есть.


================================================================
ШАГ 5. НАСТРОИТЬ NGINX
================================================================
[ ] Создай файл /etc/nginx/sites-available/okna:

    nano /etc/nginx/sites-available/okna

    Вставь:

--------- начало файла ---------
server {
    listen 80 default_server;
    server_name _;

    root /opt/okna/dist;
    index index.html;

    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
    }

    location / {
        try_files $uri /index.html;
    }
}
--------- конец файла ---------

    Сохранить: Ctrl+O, Enter, затем Ctrl+X

[ ] Включи конфиг и выключи стандартный:

    ln -s /etc/nginx/sites-available/okna /etc/nginx/sites-enabled/
    rm -f /etc/nginx/sites-enabled/default

[ ] Проверь и перезагрузи:

    nginx -t
    systemctl reload nginx

    Должно быть: syntax is ok / test is successful

ЗАЧЕМ try_files: чтобы сайт не ломался, если обновить страницу.
ЗАЧЕМ proxy_pass: чтобы сайт мог отправлять заказы в Express.


================================================================
ШАГ 6. ЗАКРЫТЬ ЛИШНИЕ ПОРТЫ
================================================================
[ ] Включи файрвол (оставляем только SSH, HTTP):

    ufw allow 22/tcp
    ufw allow 80/tcp
    ufw --force enable

    Порт 3000 наружу не открываем — в него ходит только nginx.

================================================================

[ ] Проверь по очереди:
    - страница загрузилась;

    - ссылка "Админка" просит пароль, пароль admin123 — показывает заказы.

Если всё работает — сайт на сервере. Поздравляю :)

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
================================================================
Сайт не открывается вообще
    systemctl status nginx
    nginx -t
    /var/log/nginx/error.log

Сайт открывается, но форма выдаёт ошибку
    systemctl status okna-api
    journalctl -u okna-api -n 50

"Не могу зайти по SSH"
    проверь IP и что сервер включён в панели хостинга

"npm: command not found"
    значит Node не установилась — повтори ШАГ 1

"502 Bad Gateway"
    упал Express: journalctl -u okna-api -n 50


================================================================
ПРАВИЛА БЕЗОПАСНОСТИ (раз домена и HTTPS нет)
================================================================
- Сайт работает по http:// — данные передаются открыто.
  Для учебного проекта это нормально.
- НЕ используй на этом сайте настоящие пароли и личные данные.
- Пароль админки admin123 знают все, кто читал код. Это тоже нормально
  для тренировки, но не для настоящего бизнеса.
- Когда появится домен — можно бесплатно включить HTTPS:
      apt install -y certbot python3-certbot-nginx
      certbot --nginx -d твой-домен.ру

ПОЛЕЗНЫЕ КОМАНДЫ НА ВСЯКИЙ СЛУЧАЙ

================================================================
ПОДСКАЗКА ПРО orders.json
================================================================
Заказы лежат в /opt/okna/backend/orders.json.
Этот файл есть в git, поэтому после git pull может возникнуть конфликт.
Если такое случится:
    cd /opt/okna
    git checkout -- backend/orders.json
    git pull
Но помни: эта команда затрёт заказы, которые были на сервере.
Для учебного проекта проще не доводить до конфликта.
